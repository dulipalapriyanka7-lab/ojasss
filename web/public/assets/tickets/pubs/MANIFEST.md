# Pub Events artwork — source & licence

All files in this folder are original vector artwork drawn for OJASSS (no third-party photos,
no real venue or performer images). Licence: owned by OJASSS, free to use in the app.

| File | What it shows |
|---|---|
| hero-lounge.svg | Lounge with warm pendant lights, stage spotlight, performer silhouette, crowd and bar counter |
| category-pubs.svg | Clinking glasses tile for the Explore Tickets grid |
| cover-live-music.svg / cover-dj.svg / cover-standup.svg / cover-pub-show.svg / cover-special.svg | Default event covers per event type |
| venue-placeholder.svg | Default venue image |

Real event covers, venue photos and menu photos are uploaded by admins from the Pub Events admin page.
Only upload photos you own or have the venue's/performer's permission to use.
